#raw_data Folder
This folder contains raw data files used for analysis of host-pathogen interactions. The data files are in CSV format and provide essential information on host responses, host organisms, and pathogens.

Files in this Folder:
- hostresponse.csv: Contains data on the immune responses of different hosts in relation to various pathogens.
- host.csv: Provides information about different host organisms, including their species and taxonomy details.
- pathogen.csv: Contains details about various pathogens, including their names and taxonomy identifiers.

Each of these files contains relevant data needed for further analysis of vaccine research and host-pathogen interactions. The columns in these files may vary but are organized to facilitate understanding of interactions between hosts and pathogens.
