#OLAS Data

The following folder contains all the files and data needed.

filtered_host_pathogen - all host.xlsx
This file contains a dataset of host-pathogen interactions relevant to vaccine research, including the species and corresponding taxonomic identifiers for both the host and pathogen. It also provides specific terms and definitions for animal models used in vaccine studies.

Columns:
- c_host_name: The name of the host organism (e.g., Mouse).
- c_pathogen_name: The name of the pathogen (e.g., Brucella spp.).
- c_host_id: A unique identifier for the host organism.
- c_taxonomy_id: The taxonomy ID of the host organism.
- c_pathogen_id: A unique identifier for the pathogen.
- c_taxon_id: The taxonomy ID of the pathogen.
- Term: The term used for the vaccine or animal model (e.g., "Brucella spp. vaccine Mouse animal model").
- Definition: A brief description of the term (e.g., "A vaccine animal model that uses Mouse for research of vaccine against Brucella spp.").
- Link: A URL providing additional information (e.g., https://violinet.org/vaxquery/query_detail.php?c_pathogen_id=8 ).
